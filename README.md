# Portfolio profesional de Marcos Quintana

Portfolio web en español de Marcos Quintana, desarrollador full-stack
especializado en herramientas empresariales, automatización de procesos y
modernización de sistemas.

## Sitio publicado

[Ver portfolio en GitHub Pages](https://marcosquin56.github.io/porftolio_cv_Marcos/)

## Tecnologías

- HTML semántico y accesible
- CSS responsive
- TypeScript y React para la versión de aplicación
- Open Graph para compartir el portfolio en redes

## Desarrollo local

La portada estática puede abrirse directamente desde `index.html`. Para ejecutar
la versión de aplicación:

```bash
npm install
npm run dev
```
